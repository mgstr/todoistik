Tags

A name has to be on this list before writing it in a description means anything — that is what stops #car and #Car becoming two tags. The count is what carries it. A name still in use can not be removed: removing it would be editing those items behind their back.

    {{range .Data.Tags}}
  • #{{.Name}} {{.Count}} {{template "namedelete" (dict "Use" . "Action" "/settings/tags/remove" "Fields" (dict "name" .Name))}}
    • {{end}}

Contexts

What has to be true before an action is possible at all. The values under a context are its remembered parameters — @person(Marju) — and each is removed on its own.

    {{range .Data.Contexts}} {{$ctx := .Name}}
  • @{{.Name}} {{.Count}} {{template "namedelete" (dict "Use" . "Action" "/settings/contexts/remove" "Fields" (dict "name" .Name))}} {{range .Params}} {{.Name}}{{.Count}} {{template "namedelete" (dict "Use" . "Action" "/settings/params/remove" "Fields" (dict "context" $ctx "value" .Name))}} {{end}}
    • {{end}}
