The timer in doing mode

doing.show_timer = true puts the minutes since this action went on the screen next to it: 07 up to an hour, then 1:04. It is set in the title's own size and pushed back with opacity alone — nothing about it is smaller, so it never reads as a second, quieter kind of information. It is never stored: it exists to give a feel for how long things actually take, and it dies with the mode.

Six placements, each in both themes. The screens below are rendered with the app's colours and proportions and with the rail and the key bar off, which is how the settings file currently has doing mode.
